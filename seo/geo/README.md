# SEO/GEO evidence workflow

The files in this directory are hypotheses and governance inputs, not proof of demand or AI visibility.

- `business-profile.json` replaces the retired audit vocabulary and defines the current chlor-alkali and fluoroplastic entity terms.
- `brand-facts.md` is the claim register. D-grade facts stay out of indexable content; E-grade claims are prohibited.
- `core-page-candidates.csv` is provisional until GSC and sales evidence select the first 12 pages.
- `question-bank.csv` defines buyer and brand-validation prompts. Translated prompts require native review.
- `answer-samples.csv` is an index of real samples. Store the full answer or screenshot in a separate evidence path and record platform, interface and session mode. API, web and app results must never be merged.

No sample counts as real without the answer evidence, source URLs, sampling environment and date. Brand-validation prompts are excluded from visibility rate because the brand is named in the question.
