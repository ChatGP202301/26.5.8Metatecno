# Metatecno 全站 SEO / GEO / 收录对抗式审计

证据日期：2026-08-10。北星指标：合格工业采购询盘。审计严格区分“可抓取”“可理解”“可信”“可转化”；任何分数都不是排名或 AI 引用承诺。

## 结论先行

网站并非基础 SEO 全面失效。383 个本地 HTML 都有 title、description、canonical 和一个 H1，基础校验为 `383/383; 41; 0; 0; 164`。真正的断点是版本与索引清单不一致、葡语/阿语采购内容缺口、证据与实体表达偏弱，以及 GA4 后台未能创建导致询盘闭环仍未成立。

本次生产抓取 30/30 成功，技术 SEO 88/100、GEO 59/100，发现 656 个 URL，626 个因预算未抓；审计指纹为 `52f34282311c09b6f3e04861fb2a3e4a095c06037ed05d7633ce46d4865cbe5e`。它只代表这 30 页的确定性检查。

## 第一性原理漏斗

1. 被发现：robots.txt 和 sitemap.xml 在生产抽样中均为 200，但本地 canonical、sitemap 与部署抓取没有一个统一清单。
2. 被理解：基础元数据完整，然而采购任务、规格、流程、实体 Schema、真实 FAQ 与审核来源不足，GEO 只有 59。
3. 被信任：公司与能力叙述不少，但可核验的测试标准、批次证据、案例边界、审核角色和来源日期不足；本地媒体包还缺失。
4. 产生询盘：264 页表单进入 formsubmit.co 并回到五语感谢页；本次已加隐私优先事件逻辑，但 GA4 属性和真实 Measurement ID 受后台超时阻断。

## Google 收录情况

Google 的实际收录数、趋势和原因桶目前未知。不能用 `site:` 结果替代 Page indexing。本地与 sitemap 对账得到 431 个唯一 canonical 候选：116 个“本地 indexable + sitemap”，5 个合理排除的 thank-you noindex，262 个“本地 indexable 但不在 sitemap”，48 个“在 sitemap 但本地没有对应 canonical HTML”。这只能说明发布意图冲突，不能证明 Google 是否收录。

Search Console 的目标域页面无法打开，因此 Page indexing 总量/趋势、Sitemaps 状态、16 个月 Performance、最近 90 天对前 90 天，以及 24 条 URL Inspection 的索引状态、抓取日期、发现来源和 Google canonical 均保持空值。分层样本在 `gsc-samples.csv`。

## 优先动作（最多 10 条）

1. 取得 GA4 后台可用会话，只创建一次既定属性/stream，记录 ID 并完成后台设置与 DebugView。
2. 先形成一个经批准的 canonical 发布清单，再让本地、sitemap 与部署构建一致。
3. 补齐或明确接入 152 个缺失的本地媒体目标，并对所有 HTML asset 引用做 200 门禁。
4. 明确葡语采用 pt 还是 pt-BR，建设首页、型号/改造、按图报价和 PTFE 软管承接页。
5. 仅在市场与母语审核成立后建设阿语 RTL 集群，不把机器翻译页当覆盖。
6. 将型号、泄漏腐蚀、材料选择与检修改造页改为“结论—条件—规格—证据—下一步”的工程答案。
7. 对西/法/俄 custom-gasket 等不在 sitemap 的商业页逐页作保留、合并或排除决定。
8. 给 5 个德语缺 Schema 页补与可见内容一致的 Organization/Product/Service/Breadcrumb 数据。
9. 对 45 个重复 title 页面按意图簇处理，避免机械重写或删除。
10. 校准审计规则：M005 的喷砂/太阳能术语与当前业务不符，无独立证据不得立项；T006 改用规范化 URL/重定向语义。

## 证据边界

- 未取得 Search Console 指标，因此没有任何点击、曝光、排名、国家、设备或收录趋势数字。
- SERP 研究不含搜索量与关键词难度；`keyword-map.csv` 将弱匹配明确标为 low。
- 图片像素、翻译质量、公司能力陈述和法律合规均需要各自负责人复核。
- 本地媒体缺失是可复现的源代码事实，不等同于生产环境已确认故障。
